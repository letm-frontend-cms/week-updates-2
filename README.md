# Week updates
The repository below contains the work completed during the week, along with any learning activities or projects undertaken.

The purpose of this repository is to track all learning-related work and projects completed during the mentorship program.

Each week will have a dedicated folder (e.g., Week 1, Week 2, etc.). Within the respective week's folder, every mentee should create a subfolder using their abbreviated name and upload all tasks, exercises, and project work completed during that week.

This structure will help maintain organized records of weekly progress and learning outcomes.
